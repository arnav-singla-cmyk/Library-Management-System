# 📚 Library Management System

A console-based **Library Management System developed in C++** using Object-Oriented Programming, input validation, date handling, and book/student issue management.

## 🚀 Features

* 👨‍🎓 Student management

  * Add students
  * Update student details
  * Remove students
  * Search students
  * Display student records

* 📖 Book management

  * Add books
  * Update book details
  * Remove books
  * Search books
  * Check book availability

* 🔄 Issue & Return Management

  * Issue books to students
  * Return books
  * Track currently issued books
  * Track returned books
  * Calculate due dates

* 💰 Fine Management

  * Automatic calculation of overdue fines
  * Validation of return dates

* 📅 Date Validation

  * Validates dates in `DD/MM/YYYY` format
  * Prevents invalid dates
  * Calculates due dates automatically

* ✅ Input Validation

  * Validates student IDs
  * Validates book IDs
  * Validates dates
  * Handles invalid user input

## 🛠️ Technologies Used

Run:


```bash
./library
```
